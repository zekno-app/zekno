Deploy version 2: old and new programs say plainly what to do
Runners are updated by hand, one server at a time, so every pairing of an old and a new program must either work or stop with a sentence that says which one to update. Proposed, not approved.

Update zekno to deploy to prod-1. Nothing was signed.
Today this only draws a warning in zekno status, and the deploy goes ahead. With deploy version 2 that becomes unsafe: an out-of-date zekno would sign "no domains" and a newer runner would release the app's domains. So it stops before signing. The first two sentences are the ones zekno status prints today.
