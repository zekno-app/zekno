Deploy version 2: a deploy that was overtaken can never run
Each deploy now says which deploy it was made after. If another one reached the server in between, the runner refuses it. The panel, the stage row and the marks are the ones zekno deploy draws today; only the sentence under them is new. Proposed, not approved.

Two people, or you and CI, deploy the same app at the same moment. The one that arrives second is refused, and nothing of it runs. Today the second one would run on top of the first without a word.
