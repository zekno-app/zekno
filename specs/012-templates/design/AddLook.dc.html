Good to know
Zekno does not back up this data. It is kept in a Docker volume on your server.
The image is the official one, pinned by digest. A newer one comes with a newer zekno.

The first set
postgres, mysql, mongodb and redis. Each is the software's official image.
Redis has no variable for its password. So its template starts it with one short line that writes the password, from the secret, into a file only Redis can read. The password is on no command line and in no settings file. It gives your app REDIS_URL.
