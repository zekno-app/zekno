Quick start
From a checkout to an app running on your own server.
Pre-alpha and unaudited
Try it on a server and an app you could afford to lose. Nothing here has had an external audit.
You need
•Bun 1.4.4, the version the repository pins.
•A Linux server you reach over SSH, with Docker and Compose on it.
•A folder with a compose.yaml for the app you want to run.
1
Build zekno
Zekno is not packaged yet, so you build it from the repository. It becomes one file.
TerminalCopy
git clone https://github.com/zekno-app/zekno cd zekno && bun install cd apps/cli && bun run compile # dist/zekno, for the system you are on
2
Deploy
In your app's folder, run zekno deploy. With nothing set up yet it asks for the three things it needs: your name, the server, and a name for the app.

What the program prints, captured from it. The name, the address and the codes are examples.
In those few lines:
•Your key was made and stored in your system keychain. It never leaves your machine.
•The runner was installed on the server over SSH, after its checksum matched the one your zekno holds.
•The secret was encrypted for that server only, and the deploy was signed with your key.
•The runner checked the signature before it decrypted or started anything.
