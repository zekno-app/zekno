Templates
zekno add puts a ready-made service, such as a database, into your app, with its passwords made on your machine.
UsageCopy
zekno add [<template>] [--name <service>] [--for <service>] [--app <app>] [--server <name>] [--yes] zekno add --list [--json] zekno add <template> --show [--json]
A template is a service someone already wrote well. Each one is a data file inside zekno, reviewed before it ships. Nothing is downloaded when you use one.
Adding one
zekno add postgres shows what it will add, asks once, and writes nothing until you say yes. Nothing is deployed until you deploy.

The password is never shown. The connection secret is built from it for the services you chose.

Each password is 32 letters and digits from your system's random source. Each service keeps its data in a volume named for it and publishes no port.
Whole or not at all
The service and its secrets are added together. If one part fails, the file and the secrets are put back as they were.
