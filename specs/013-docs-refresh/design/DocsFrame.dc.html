What a frame is
The real program's output
Captured by a command in the repository, against stand-ins. Never drawn or edited by hand.
Text
You can select and copy it. It is the terminal's own characters, in the CLI's colours.
The site's code block
Same border, corner and title bar as every code block of the docs. The left of the bar says what it shows, the right the command or the size.
Kept true by a test
When the program prints something else, the test fails and names the screen.
Example values only
A made-up name, an address from the range kept for documentation, codes made for the capture.
Described for screen readers
Each frame carries a sentence that says what the screen shows.
What it is not
Not a photograph
No picture to go stale or blur. The one exception is the README, where GitHub needs a picture: it is made from the same capture.
Not a window
No fake window buttons, no shadow, no animation.
Not a second colour scheme
The site is dark for everyone, so there is one set of colours.
