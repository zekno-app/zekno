What is sent
zekno sends the folder's files, except those .dockerignore lists, as docker build would. It never sends a link. It leaves out .git unless the settings name it, and every file that looks like it holds secrets unless the settings name it and you agreed to it on this machine. That list holds .env and .env.* in any folder, .npmrc, .netrc, .git-credentials, and files whose name or content marks a private key. It is a convenience, not a guarantee: a secret in a file of another name is sent.

New · K33 · Docs · Building from source, Files a build fetches

Files a build fetches
zekno refuses an ADD line that fetches from the server itself or from a private address. It reads only the address as written: a name that leads to a private address on the server, or a public address that redirects to one, is not caught. What holds a fetched file to its content is the checksum every such ADD line must carry.
