New · K30 · Docs · What is kept where, the server
Docs · What is kept wherestorage.mdx
On the server, including the secret records it keeps, see the runner page.
For an app built on the server, the runner's folder also holds packs/, the code of a deploy waiting to be built, at most 2 GiB and none older than 24 hours; building/, the code of the build under way; kept/, a record of each image it keeps, as the server's word; and buildx/, a note of each build until Docker's record of it is removed. Each build has a work folder of its own outside the runner's folder, in zekno-unpacked/, deleted when the build ends. Docker's own storage holds the images, the build cache and, until the runner removes it, Docker's record of each build.

Files a build fetches
zekno refuses an ADD line that fetches from the server itself or from a private address. It reads only the address as written: a name that leads to a private address on the server, or a public address that redirects to one, is not caught. What holds a fetched file to its content is the checksum every such ADD line must carry.
