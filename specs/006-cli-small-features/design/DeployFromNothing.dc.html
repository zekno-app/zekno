How it behaves
Only what is missing is asked. With a key already, the first block is not shown, and the opening line counts what is left: “Two things first: a server, this app.”
Each thing is finished before the next question. Leaving keeps what was made:
✖ Nothing more was done. What was set up so far is kept: run zekno deploy again to carry on.
At the hidden prompt, esc skips that value and ctrl-c leaves.
Only zekno deploy starts from nothing. Another command says:
No team on this machine yet. Run `zekno deploy` in a project folder, or `zekno init`.
In a script nothing is asked: the command stops with the sentence and exit status it has today.
