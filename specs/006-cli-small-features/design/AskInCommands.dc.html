Which app, and a typed answer
$ zekno deploy
✔ Server  prod
? Which app on prod?
❯demodeploy 4, runningapideploy 12, running+ a new app
↑↓ move   enter choose   esc leave
“+ a new app” is offered by deploy only.
? Name for the new app › my-folder 
The folder’s name is filled in. Enter keeps it.
A wrong answer is said, and asked again:
? Name for the new app › My App
Use lowercase letters, digits and hyphens, starting with a letter or a digit.
In a script or a pipe, nothing is ever asked:
$ zekno status | cat
Say which server with `--server <name>`, or link this folder to it with `zekno link`, which keeps it in zekno.json.
Exit status 2, as today.
