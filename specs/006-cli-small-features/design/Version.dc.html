zekno --version: instant, never uses the network
$ zekno --version
zekno 0.1.0
runner 0.1.0, the runner release this zekno installs
$ zekno --version --json
{"zekno":"0.1.0","runner":"0.1.0"}
It works with no key, no profile and no terminal, and changes nothing.
The first line of zekno doctor shows the same, and makes the same check as zekno version:
!zekno0.1.0, installs runner 0.1.0A newer release exists: 0.2.0. Update zekno to get it.
zekno version: also asks whether a newer release exists
$ zekno version
zekno 0.1.0
runner 0.1.0, the runner release this zekno installs
✔ This is the newest release.
When a newer one exists:
! A newer release exists: 0.2.0. Update zekno to get it.
With no network, a slow answer, or an answer that is not a version:
Could not check for a newer release.
None of the three changes the exit status. zekno asks GitHub once, sends nothing about you, your team or your servers, gives up after 3 seconds, and never downloads or installs anything because of the answer.
Only zekno version and zekno doctor check. No other command does, and nothing checks in the background.
