The sections are the screen's sections
sourcewhat runs. Now: an image.
deployhow it starts, restarts, and its limits.
networkingthe port it listens on, and one to publish.
variablessecrets by name, and plain values.
volumesnamed volumes and where they are mounted.
Places kept for later versions
source.buildbuild from this folder (C1)
deploy.predeploya command run before the new version starts
deploy.healthchecka path that must answer (C3)
deploy.replicasseveral copies, behind the proxy
networking.domainsdomains with HTTPS (C3)
A file that uses one today is refused with a sentence. A file written today stays valid when they arrive.
What it can never hold
A secret's value. A path outside the project. A folder of the server. A command for your own machine. Another file to include.
Why this form
It is the form zekno.json already has, it is read strictly with no new tool, and the settings screen can rewrite it exactly. It has no comments: that is the cost.
