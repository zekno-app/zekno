A value that is not allowed changes nothing. Exit status 2:
$ zekno settings set web.memory lots
✖ That is not a memory limit.
Use a size such as 512m or 1g.

How it behaves
zekno settings reads the file in this folder. It contacts no server.
set and unset change one setting. With no terminal they need --yes.
zekno settings init starts a file by asking for the image.
Piped, each setting is one line, with tabs:
web deploy.memory 1g web networking.port 3000
--json gives the file's own data.
In a folder with no settings file:
This folder has no settings file. Run zekno settings init to start one.
