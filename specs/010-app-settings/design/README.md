# Boards for app settings

A copy of the row "App settings (spec 010)" of the design canvas
(https://claude.ai/artifact/BVuvZPZTReLa4TSHfyzMJW). **Approved by the maintainer on 2026-11-16.** They are binding for the look: colours, what is
bold and what is dim, spacing and alignment. `design.md` is binding for the words.

| Board | Shows |
|---|---|
| `SettingsFile.dc.html` | The settings file, its sections, the places kept for later versions |
| `AppSettings.dc.html` | The settings screen of the full-screen app |
| `AppSettingsEdit.dc.html` | Changing one setting from that screen |
| `CmdSettings.dc.html` | `zekno settings`: showing, changing, the Compose text, piped output |
| `SettingsDeploy.dc.html` | `zekno deploy` from settings, and each way the file cannot be used |

They are HTML mock-ups of terminal screens, 14px Geist Mono on the app's colours. Open one in a
browser beside the canvas's `support.js`, or look at the canvas.
