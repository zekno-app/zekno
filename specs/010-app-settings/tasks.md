# Tasks: App settings

**Input**: Design documents from `/specs/010-app-settings/`

**Prerequisites**: plan.md, spec.md, design.md and the boards in design/ (binding), research.md, data-model.md, contracts/ (settings-file.md, compose-text.md, commands.md, deploy.md, app-screen.md), quickstart.md

**Tests**: included. The constitution requires unit tests for logic with branches (Principle VII), and the decisions require screens rendered through Ink, single commands through the stand-in terminal, `test/plain/plain-unchanged.test.ts` green with `plain-at-head.ts` never edited, a byte-for-byte test of `zekno settings compose` against the signed deploy, and an independent security review.

**Organization**: grouped by user story, in priority order. Paths are relative to the repository root; commands run in `apps/cli` unless said otherwise. Within a task pair, the test task comes first and is seen to fail. At the end of every task: `bun test` in `apps/cli` passes for what the task touched, `bun run lint` in `apps/cli` finds nothing, and `bun run format` in `apps/cli` leaves no change (`git diff --stat` after it shows only the task's own files). At the end of every phase the whole of `bun test` in `apps/cli` passes.

**Before you start**: read research.md R9 (what was chosen where the spec, design.md and the boards disagree or are silent). Every look and sentence no board shows is built as the contracts write it and listed in your report, for the maintainer to review on the real program.

**Sentences** are quoted from the contracts by their ids: SR1 to SR9, SJ1 to SJ5, SV1 to SV33, SL0 to SL5 in contracts/settings-file.md; SH1 to SH3, CS1, CS2 and CS4 to CS17, IN1 to IN6 in contracts/commands.md; DP1, DP2, DP3 and DP5 in contracts/deploy.md; AS1 to AS7 in contracts/app-screen.md. Copy them from there exactly; they all live in `apps/cli/src/settings/words.ts`. Never use the word "agent" for any part of Zekno: the program on a server is the runner. No em dashes in any sentence.

**Never**: change a file under `packages/core/` or `apps/runner/`; edit `apps/cli/test/plain/plain-at-head.ts`; add a dependency; add an option to `parseArgs`; edit `apps/cli/e2e.config.ts` (research R7); run `bun run test:e2e`, `next dev` or `next build`; use the real keychain, `ssh` to a real host, or the network.
